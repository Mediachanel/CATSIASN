# UI/UX

Identitas sementara CAT Nusantara menggunakan hijau hutan, warna kertas, tipografi editorial, dan komponen dengan kontras yang jelas. Halaman publik responsif dan menyatakan layanan independen. Halaman peserta dan admin belum diimplementasikan.

Rencana layar ujian: header identitas dan waktu server, satu soal serta pilihan A?E, status penyimpanan, kontrol sebelumnya/lewati/simpan/selesai, dan peta nomor soal. Pada ponsel peta berpindah ke panel yang dapat dibuka. Keyboard, fokus terlihat, teks alternatif media, kondisi loading/error, dan konfirmasi submit wajib diuji. Jangan gunakan screenshot resmi BKN.
